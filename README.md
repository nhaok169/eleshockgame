# EleShock · 双智能体作息博弈

不完全信息作息对抗：两个智能体每小时选择睡觉、发呆或探查。睡不够会被系统强制补觉；探查打中对方睡觉会电击，打中发呆会被反杀。先被电满 15 次者败；否则 720 小时后被电少者胜。

仓库：[nhaok169/eleshockgame](https://github.com/nhaok169/eleshockgame)

```bash
git clone https://github.com/nhaok169/eleshockgame.git
cd eleshockgame
```

## 两种玩法

| 模式 | 入口 | 需要什么 |
| --- | --- | --- |
| 单人 vs 脚本 AI | 浏览器打开 [`a.html`](./a.html) | 无，双击即可 |
| 局域网双人 | [`lan-room/`](./lan-room) 里 `node server.js` | [Node.js](https://nodejs.org/)、同一 Wi‑Fi、两部手机浏览器（不用装 App） |

## 单人怎么玩

1. 打开 `a.html`。你是 **B**，**A** 是脚本。
2. 每个整点：睡眠（可一次指定 1–8 小时）、发呆 1h、或探查 1h。
3. 睡眠会连续推进，直到被电醒、达到每日 8h 上限、或自然醒。
4. 共享日志里，对方未探查的动作显示 `?`。
5. 页面底部 **上帝视角** 只给观察者，局内智能体看不到。

## 局域网双人

电脑当服务器，两部手机当座位 A / B，互看不到未揭示动作。

```bash
cd lan-room
node server.js
```

终端会打印裁判席和手机链接。详细说明见 [`lan-room/README.md`](./lan-room/README.md)。

- 双方都锁定后才结算。
- 座位页只有自己的 T、睡眠、过滤日志和系统判决。
- 上帝视角在电脑裁判席 `/host.html`，玩家不要打开。

## 规则

### 时间与动作

- 整点结算，每小时双方各行动一次，时钟 +1。
- 动作只有三种：`sleep`（睡觉）、`idle`（发呆）、`scout`（探查）。

### 睡眠累积

睡眠以小时段 `[h, h+1)` 为单位：

- 在整点 `h` 选择 sleep，且该小时没被电 → 该小时段 +1h。
- `x` 点选睡 `m` 小时，若在 `y` 点被电醒（`x ≤ y < x+m`）→ 累计 `y − x` 小时；被电那一小时 +0；在 `y+1` 重新选择。
- 一直没被电 → 到 `x+m` 点自然醒，累计 `m` 小时，在 `x+m` 点重新选择。

示例：3:00 选睡 4h

| 事件 | 睡眠累计 | 下一次选择 |
| --- | --- | --- |
| 3:00 被电 | +0 | 4:00 |
| 4:00 被电 | +1 | 5:00 |
| 6:00 被电 | +3 | 7:00 |
| 7:00 自然醒 | +4 | 7:00 |

每天最多 8h。`todaySleep >= 8` 时，sleep 意图被改写为 idle。

### 死线 T

- 昨天睡眠 **≤ 6h** → 今天 T = 8h（补觉）；否则今天 T = 6h。
- 第 1 天无前日数据，T = 6h。
- 睡满正好 6h，次日仍补觉。要让次日 T = 6，昨天必须睡到 7h 或 8h。

### 强制睡眠

每个整点 `h` 检查：

```text
(24 - h) + todaySleep == T
```

恰好相等时，系统覆盖该智能体本小时意图为 sleep，再按普通睡眠结算。

- 该小时没被电：`todaySleep += 1`，下一整点仍满足等式，继续强制。
- 该小时被电：`todaySleep += 0`，下一整点左式变为 T−1，系统放手。
- 不需要额外的「已断」标志。自愿睡眠被打断后，若之后再次走到等式上，仍可能被强制。

### 探查与电击

| B | A | 结果 |
| --- | --- | --- |
| 探 | 探 | 无事 |
| 探 | 睡 | A 被电 +1，A 该小时睡眠 +0 |
| 探 | 呆 | B 被电 +1（反杀） |
| 睡 | 探 | B 被电 +1，B 该小时睡眠 +0 |
| 呆 | 探 | A 被电 +1（反杀） |

### 信息

- 双方共享同一份日志。
- 自己的动作永远可见。
- 对方动作只有在本小时发生探查（任一方 scout）时才揭示，否则显示 `?`。
- 局内看不到对方的 T 和今日睡眠。电击次数公开（电击一定发生在探查小时）。
- 脚本 AI / 座位页都不能读上帝视角。

### 胜负

1. 任一方累计被电满 15 次，立即结束。
2. 720h 后无人满 15：被电少者胜，相同则平局。

## 上帝视角

给人类观察者的对照通道，**不是**局内信息。

单人版在 `a.html` 底部；双人版在裁判席。可以看到：

- A / B 每个整点的真实动作
- 意图 vs 实际（`*` = 死线强制）
- 该小时睡眠是 +1 还是被电 +0
- 是否揭示、谁被电
- 双方真实 T 与今日睡眠
