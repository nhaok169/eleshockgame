# 局域网双人房

电脑当服务器，两部手机连同一 Wi‑Fi，**用浏览器打开链接即可，不用装 App**。

根目录的 `a.html` / `README.md` 是单人打脚本 AI 的版本，本文件夹不改它们。

## 怎么开

电脑需要已安装 [Node.js](https://nodejs.org/)。然后：

```bash
cd lan-room
node server.js
```

终端会打印类似：

```text
裁判席（建议电脑打开）
  http://127.0.0.1:8766/host.html

大厅     http://192.168.x.x:8766/
手机 A   http://192.168.x.x:8766/play.html?seat=A
手机 B   http://192.168.x.x:8766/play.html?seat=B
```

1. 电脑浏览器打开裁判席。
2. 两部手机分别打开 A、B 链接（或打开大厅再点座位）。
3. 各选动作并锁定。**双方都锁定后才结算**，看不到对方选了什么。
4. 电脑不要休眠。结束时在终端按 `Ctrl+C`。

Windows 若弹出防火墙，选允许局域网。有的路由器「访客网络 / AP 隔离」会让手机访问不到电脑，换成普通 Wi‑Fi。

地址必须是 `http://`，不要写成 `https://`。

## 座位上看得到什么

每个人只看到：

- 自己的动作、自己的 T、自己的今日睡眠
- 双方累计被电（电击一定发生在探查小时，规则上公开）
- 过滤后的日志：己方动作永远可见，对方未探查为 `?`
- 系统判决：被电、反杀、强制睡眠、被电醒后下一点重选

看不到：对方 T、对方睡眠、对方未揭示动作、对方锁定了什么、上帝视角。

睡眠可一次锁 1–8 小时。你还在睡、对方这一小时已经走完时，只等对方再锁。被电醒或满 8h 会打断站立睡眠。

若整点已满足强制睡眠公式，系统自动覆盖为睡，不必再点。

## 裁判席

电脑上的上帝视角可以看到双方真实意图、动作、睡眠和谁已锁定。玩家手机不要打开 `/host.html`。

可以把 A/B 链接复制发到微信。也可以踢掉占座的人、重置本局。

## 文件

```text
lan-room/
  engine.js      # 结算（双方同时提交意图）
  server.js      # 局域网 HTTP 服务
  package.json
  public/
    index.html   # 大厅
    play.html    # 座位 A / B
    play.js
    host.html    # 裁判席
    host.js
    style.css
```

规则与根目录 README 中的权威定义相同。区别只有：A 也是人类，不再调用脚本 `decideA`。
